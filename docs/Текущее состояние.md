## Цель
Telegram-бот подготовки к экзамену ПДД категории B с онбордингом обмена прав Казахстан → Россия и восемью функциями MVP.

## Подтверждённое состояние
- Репозиторий: https://github.com/Marlett13/n13-pdd-bot
- Импортёр кандидата ABM структурно принимает 40 билетов, 800 вопросов и 541 изображение. Источник: etspring/pdd_russia.
- Считыватель `app/question_bank.py` добавлен; интеграционный тест успешно прошёл в GitHub Actions: https://github.com/Marlett13/n13-pdd-bot/actions/runs/39904370933
- Архив кандидата сохраняется в артефакте Actions, не в постоянной базе проекта.

## Ограничения
- Не проводилась официальная сверка правильных ответов и актуальности материалов.
- В репозитории пока нет интегрированного с Telegram готового бота; VPS не развёрнут.
- Не подтверждены права использования всех иллюстраций. Не объявлять набор официально одобренным.

## Следующее действие
Добавить приложение aiogram с /start, согласием и чтением выбранного билета через QuestionBank; покрыть сквозными тестами. Предусмотреть постоянный версионированный источник данных перед VPS.
