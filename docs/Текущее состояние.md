## Установленный путь ошибки, скриншот 15:18
- Последняя строка журнала: `PermissionError: [Errno 13] Permission denied: '/srv/n13/app/bot.py'`. Отказ чтения исходного кода подтверждён; SQLite не является указанным проблемным файлом.
- Dockerfile запускает bot (UID 10001), но COPY ранее сохранял права исходников без нормализации. Добавлен chmod a+rX только для app/tools в образе. CI воспроизводит режим 600/700 и проверяет настоящий импорт контейнера под UID 10001 при read-only FS и без сети.
- Новый tools/repair_code_permissions.sh предназначен для crash loop: проверяет scope/том/отсутствие bind-mount кода и локальных изменений; fast-forward на проверенный SHA; сборка и импорт непривилегированным пользователем ДО остановки; остановка только pdd; закрытый tar-архив всего каталога данных включая SQLite/WAL; замена только pdd с обоими Compose-файлами; сохранение .env/volume; откат образа при провале проверок. На VPS пока не выполнен. Это отдельный путь от online-backup recovery, который не работает при crash loop.
