## Цель
Telegram-бот подготовки к экзамену категории B (первоначальный сценарий обмена казахстанских прав на российские), восемь функций MVP.

## Подтверждённое состояние
- Код хранится в https://github.com/Marlett13/n13-pdd-bot
- Кандидат ABM из etspring/pdd_russia: 40 билетов, 800 вопросов, 541 изображение; структура и пути прошли GitHub Actions.
- Есть модуль `app/question_bank.py` и успешно завершённый интеграционный тест вопросов.
- В `app/bot.py` добавлен aiogram 3: /start, согласие, выбор цели/страны/категории, прохождение билета, итог и /delete_data.
- SQLite `app/storage.py` сохраняет согласие, настройки, ответы и позицию тренировки; модульные тесты хранения прошли в GitHub Actions 39953941177.
- `requirements.txt` и автоматическая проверка импортируемости Telegram-слоя добавлены в CI.

## Не подтверждено или отсутствует
- Запуск через реальный Telegram и деплой на VPS отсутствуют.
- SQLite-хранение реализовано и прошло модульные проверки; восстановление через реальный Telegram и конкурентные callback-запросы пока не испытаны. Официальный симулятор ещё не подключён.
- Набор вопросов не сверен по содержанию с актуальными официальными билетами ГИБДД.
- Реализованный экран согласия является прототипом, не окончательным юридическим текстом.
- Значение токена не хранится в коде. GitHub secret PDD_BOT_TOKEN прошёл проверку getMe в Actions 39955361334.
- Dockerfile, compose.yml, .env.example и подготовка постоянного тома данных добавлены в репозиторий; сборка CI запущена, развёртывание на VPS не выполнялось.
