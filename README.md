# N13 ПДД

Telegram-тренажёр для подготовки к теоретическому экзамену ГИБДД, первоначальный сценарий: обмен удостоверения Казахстан → Россия, категория B.

## Состояние (2026-10-23)
- Репозиторий создан. Ни бот, ни база из 800 вопросов пока не развёрнуты.
- Первый технический этап: импорт кандидата ABM и автоматическая проверка структуры.
- Тестовый набор **не утверждён** как официальный или актуальный до сверки правильных ответов и иллюстраций.
- Не хранить реальные ответы юридического опроса (гражданство, действительность удостоверения, уточнение ГИБДД), кроме временной памяти.

## MVP
Билеты 1–40; обучение по темам; работа над ошибками; симулятор ГИБДД; история попыток; сложные вопросы; прогресс; продолжить позже.

## Данные
Workflow `N13 ABM candidate audit` скачивает сторонний набор с https://github.com/etspring/pdd_russia, проверяет 40×20, ответы и изображения, сохраняет отчёт в артефакт GitHub Actions. Он **не публикует** вопросы в работающем боте. Для проверки актуальности нужен официальный источник Госавтоинспекции.

## Безопасность
Не коммитить токены Telegram, личные данные и реальные пользовательские результаты. Прежде чем сохранять профиль, получить необходимое согласие.
